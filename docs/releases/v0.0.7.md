## MePaste v0.0.7

本次更新聚焦日常复制粘贴体验，新增直接粘贴、纯文本操作、永久收藏、隐私控制和数字快捷键。

### 更顺手的粘贴

- 点击卡片或按 Return 使用记录；授权辅助功能后，直接粘贴到原应用的光标处。
- 未授权辅助功能或关闭直接粘贴时，仍可复制到剪贴板并返回原应用，再自行按 ⌘V 粘贴。
- 新增 ⇧Return 和右键纯文本操作，去除格式且不修改保存的原始内容。
- 新增 ⌘1…⌘9 快捷操作，编号对应当前历史、搜索结果或收藏列表的前九条记录；加 Shift 可使用纯文本版本。
- 直接粘贴等待原应用恢复焦点和快捷键修饰键释放；期间切换应用、改写剪贴板或重新打开面板会取消待执行的粘贴。

### 永久收藏

- 点击卡片星标或右键“收藏并永久保留”，将常用内容加入收藏。
- 新增“全部历史 / 收藏”切换，支持在收藏中搜索。
- 收藏不受保留天数和记录数量限制，也不占普通历史额度。
- 重新复制相同内容会保留收藏状态，不产生重复收藏。
- 清空普通历史时保留收藏；删除全部记录（含收藏）需要单独确认。
- 取消收藏后立即重新应用普通历史容量策略，已过期或超出容量的记录可能被清理。

### 隐私控制

- 在设置中选择不记录的应用，排除名单会持久化。
- 菜单栏和设置均可暂停 / 恢复记录，暂停状态在重启后保持；恢复时不补录暂停期间的内容。
- 带有敏感、临时或自动生成标记的整次复制都会被忽略，修正此前仅丢弃临时标记而可能保留正文的行为。
- 暂停或调整排除名单时取消尚未完成的采集，避免旧任务越过隐私边界。

### 界面与稳定性

- 设置窗口分为通用、快捷键、历史与收藏、隐私四个页签，提供辅助功能权限状态和操作说明。
- 菜单栏显示收藏数量及暂停状态。
- 优化非激活历史面板的焦点处理，避免重复打开时与应用激活产生竞态。
- 正常退出前等待待保存的历史和收藏落盘，避免即时退出丢失最近修改。
- 增加 42 项回归测试，覆盖收藏、纯文本、隐私边界、数字快捷键及直接粘贴安全降级。

### 兼容性与使用提示

- 继续支持 macOS 13 及以上系统，以及 Apple Silicon 和 Intel Mac。
- 兼容旧版历史数据，旧记录默认未收藏，无需手动迁移。
- 建议将 MePaste.app 安装到 /Applications 后，在“设置 → 通用”中按需授权辅助功能；启动和普通复制不会自动申请权限。
- 纯文本支持已有文本表示及 RTF；无法可靠转换的图片、混合文件条目或只有 HTML 的内容不会覆盖当前剪贴板。
- 应用排除按采集时的前台应用判断，新增规则不删除旧历史；未标记的敏感内容无法保证自动识别，请按需排除应用或暂停记录。
- 本次已完成隔离界面验证和自动化测试，授权后的真实跨应用粘贴尚未完成实机验收。
