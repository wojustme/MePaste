## MePaste v0.0.2

本次更新聚焦历史搜索和中文输入体验，让剪贴板历史更容易找，也更适合日常中文环境使用。

### 新增

- 历史面板新增搜索框，可按文本内容、标题、副标题、文件名和剪贴板类型过滤记录。
- 搜索时会显示匹配数量和总记录数，方便判断当前筛选范围。
- 搜索结果会自动同步当前选中项，左右方向键和 Return 会作用在筛选后的记录上。

### 修复

- 修复中文输入法组词或选择候选词时，按 Return 被误触发为复制当前历史记录的问题。
- 修复中文输入法合成文字时，Esc 被误处理为清空搜索或关闭历史面板的问题。

### 开发与兼容性

- 补充 Swift 6 主线程隔离兼容修正，保持 GitHub Actions Release 构建稳定。
