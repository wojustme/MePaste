## MePaste v0.0.8

本次更新全面升级视觉界面与软件图标，重构大体积历史存储与渲染链路以显著提升性能，并优化再次打开面板时的历史定位体验。

### 界面与图标全面升级

- 全新设计的 macOS 立体磨砂玻璃风格应用图标，符合 macOS HIG 连续超椭圆规范。
- 历史面板升级为底部悬浮磨砂玻璃 Dock，具备柔和顶光、自适应描边与 `0.16s` 顺滑上浮入场动效（关闭与恢复焦点保持零延迟）。
- 顶部新增品牌标识、带计数气泡的「全部历史 / 收藏」切换器、「全部 / 文本 / 图片 / 文件」一键类型筛选、聚焦高亮搜索框，以及暂停记录与设置快捷入口。
- 卡片按内容语义着色（文本、代码、链接、HEX 色值、图片、文件），新增 HEX 色块预览、链接域名徽章、代码等宽排版与悬停快捷操作条（纯文本 / 仅复制 / 删除）。
- 设置窗口升级为统一品牌头部与分段导航栏，新增历史容量进度卡片、键帽风格快捷键速查表、带真实应用图标的排除应用列表，以及带悬停反馈的快捷键录制器。

### 更顺手的二次呼出体验

- 选中并复制/粘贴任意历史记录后，该记录会自动置顶到列表首位（`⌘1`）并持久化顺序，再次打开 MePaste 时第一时间高亮并滚动定位到刚选用的记录。
- 置顶复用原记录标识、格式与收藏状态，不触发重复采集或缩略图重新解码。
- 搜索支持空格分隔的多词乱序匹配；按 `Esc` 依次清空搜索词、清空类型筛选、关闭面板。

### 性能优化

- **外部 Blob 存储**：≥ 64 KB 的大体积剪贴板内容（如截图与大图）按 SHA-256 独立存放在 `blobs/` 目录，避免每次复制或收藏时全量重编码 `history.json`，并自动回收孤立 Blob；完全向后兼容旧版内联 JSON 历史。
- **O(1) 去重与哈希**：后台预计算与顺序无关的 `SHA256` 内容指纹，消除主线程插入去重时的全量数据比对与临时 `Set` 分配。
- **缩略图零闪烁命中**：支持主线程同步读取已缓存缩略图并合并并发解码任务，记录删除或清空时同步释放缓存。
- **列表零冗余重绘**：缓存收藏数与前九条快捷编号映射，移除文本卡片嵌套 `ScrollView`，为卡片实现 `Equatable` 差量更新，左右键切换选中项仅重绘受影响卡片。

### 兼容性与验证

- 继续支持 macOS 13 及以上系统（Universal 2：Apple Silicon & Intel）。
- 自动兼容旧版 `history.json`，升级后无需手动迁移数据。
- 新增外部 Blob 存储、旧版 JSON 兼容、缩略图同步命中/回收、多词搜索、类型筛选及选中置顶等回归测试，共 85 项自动化测试全部通过。
