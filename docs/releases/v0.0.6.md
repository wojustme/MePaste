## MePaste v0.0.6

本次更新聚焦剪贴板历史搜索与预览的性能，减少重复计算和隐藏面板的后台刷新，并新增菜单版本号，方便区分开发构建与正式发布。

### 性能优化

- 缓存记录摘要与搜索索引，搜索在后台执行，并对连续输入进行防抖和取消过时任务。
- 缓存筛选结果，左右方向键切换记录时不再反复扫描整个历史库。
- 图片按需生成并缓存缩略图，避免卡片刷新时反复创建原始图片。
- 长文本卡片最多预览 2,000 个字符；全文搜索与复制仍保留完整内容。
- 隐藏历史面板时释放其视图，停止隐藏卡片的日期、动画与预览任务更新。
- 历史没有变化时，不再在启动或修改容量设置后重写整个历史文件。

### 版本信息

- 菜单底部、“退出 MePaste”上方新增只读版本号。
- 本地构建显示 `dev-<短 commit ID>`，包括本地生成的 APP 和 DMG。
- GitHub Release 构建显示对应的发布 tag，例如 `v0.0.6`。
- Commit ID 在构建时嵌入，安装后的应用无需读取源码目录或执行 Git。

### 稳定性与发布

- 搜索进行中禁止 Return 复制旧查询结果，避免误选过时内容。
- 保持异步准备的剪贴板记录按复制时间排序，防止较旧结果覆盖较新的重复记录。
- 在加载历史完成后启动监听，避免异步加载覆盖新捕获的记录。
- 每次打包都会重新构建应用，并校验发布版本，避免复用错误版本或渠道的旧 APP。
- 增加自动化回归测试，覆盖搜索取消、键盘选择、容量清理、富文本与多条目恢复、旧历史格式兼容、缩略图缓存及版本生成。

### 兼容性

- 继续支持 macOS 13 及以上系统，以及 Apple Silicon 与 Intel Mac。
- 保持现有历史数据格式，无需迁移剪贴板历史。

### 发布环境修复

- 将发布工作流迁移到受支持的 macOS 15 runner，修复旧 macOS 14 runner 导致发布任务自动取消的问题。
- 使用与本地验证一致的 Xcode 26.2 构建并运行回归测试。
- `v0.0.5` 的发布任务在构建前被取消，未生成正式 Release；本版包含其全部性能优化与版本号改进。
